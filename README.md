# Madhav Ecommerce Sales Dashboard

An interactive Ecommerce Sales Dashboard recreated in Microsoft Power BI as a hands-on learning and dashboarding practice project.

## 📊 Project Overview

This project focuses on creating an interactive Ecommerce Sales Dashboard in Microsoft Power BI.

The dashboard provides a visual overview of sales, profit, quantity, customer performance, payment methods, product categories, sub-categories, states, and monthly profit/loss.

The primary objective of this project was to practice dashboard creation, data visualization, report layout, and interactive filtering in Power BI.

## 📈 Dashboard Highlights

The dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Average Order Value
- Monthly Profit/Loss Analysis
- Top States
- Quantity by Category
- Top Customers
- Quantity by Payment Mode
- Profit by Sub-Category
- State and Quarter-based filtering

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualisation
- Dashboard Design

## 🎯 Learning Objective

The objective of this project was to gain practical experience in:

- Creating an interactive Power BI dashboard
- Working with sales data
- Creating KPIs and measures
- Using different Power BI visualisations
- Applying filters and slicers
- Structuring a dashboard layout
- Presenting data through visual reports
- Understanding how data can be transformed into a dashboard
